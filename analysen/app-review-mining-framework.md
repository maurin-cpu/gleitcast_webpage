## Research Protocol

### Search Queries (Google)
For each app, use these search patterns:

```
"[app name] paragliding review"
"[app name] app store review complaints"
"[app name] reddit paragliding"
"[app name] vs [competitor]"
site:reddit.com/r/freeflight "[app name]"
site:paraglidingforum.com "[app name]"
```

### Platforms to Check
- [ ] Apple App Store (direct reviews)
- [ ] Google Play Store (direct reviews)
- [ ] Reddit (r/freeflight, r/paragliding)
- [ ] Paraglidingforum.com
- [ ] YouTube video comments
- [ ] Facebook paragliding groups
- [ ] Review aggregator sites

### Priority Filter
1. ⭐ 1-star reviews (highest pain)
2. ⭐⭐ 2-star reviews
3. ⭐⭐⭐ 3-star reviews (most honest)
4. Look for: "I wish...", "It would be great if...", "The only problem is..."
