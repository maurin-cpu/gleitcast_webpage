## DATA QUALITY CHECKLIST

### For Each Quote Extracted

- [ ] App name recorded
- [ ] Platform noted (iOS/Android/Reddit/etc.)
- [ ] Source specified (App Store/Reddit thread/YouTube/etc.)
- [ ] Date captured (when review/comment posted)
- [ ] Rating included (if applicable)
- [ ] Username saved (for reference)
- [ ] Full verbatim quote (exact words, in quotes)
- [ ] Primary theme tagged
- [ ] Sentiment coded (pain/gain/unmet_need/switching_trigger)
- [ ] Severity noted (if pain point)
- [ ] Specific feature mentioned (if applicable)
- [ ] Competitor comparison noted (if mentioned)

### Quality Filters Applied

- [ ] Skipped generic reviews ("Great app!" with no detail)
- [ ] Filtered likely fake reviews (patterns identified)
- [ ] Prioritized detailed reviews (3+ sentences)
- [ ] Focused on recent reviews (last 6-12 months)
- [ ] Balanced across star ratings (not just 1-star or 5-star)
- [ ] Captured context (version number, timing, updates)
- [ ] Noted geographic differences (if applicable)

## EMERGENCY SHORTCUTS (If Running Out of Time)

### If you only finish 50% of research:
- [ ] Prioritize: burnair, XCTrack, Meteo-Parapente (top 3)
- [ ] Focus on: Pain points + Feature requests (skip some praise)
- [ ] Minimum: 100 quotes from top 3 competitors
- [ ] Still valuable for MVP definition

### If you only finish 25% of research:
- [ ] Do the 4-hour sprint instead
- [ ] Get directional insights
- [ ] Validate with pilot interviews
- [ ] Come back for deep dive later

### If you can't do any research:
- [ ] Read existing competitor analysis reports (if available)
- [ ] Interview 10-15 pilots directly (primary research)
- [ ] Test apps personally
- [ ] Better to do primary research than no research

---

**Remember:** Perfect is the enemy of done. It's better to do a quick 4-hour sprint and get directional insights than to plan for a 3-day deep dive and never start.

**Start now. Start small. Iterate.**
